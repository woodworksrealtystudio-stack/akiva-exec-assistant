# Follow-Up Sequence Builder

Builds a 3-touch follow-up sequence (text, email, text) personalized to the contact and their situation. Reads portfolio context before writing.

---

## Process

1. Read `context/portfolio.md` for any existing context on this person (broker, tenant, prospect).
2. Ask for any missing details.
3. Write the 3-touch sequence.
4. Note recommended timing between each touch.

---

## Required Inputs

- Contact name + relationship (broker / prospect tenant / current tenant / LL contact)
- Stage (new LoopNet inquiry / after tour / after LOI / lease negotiation / going cold)
- Last interaction (what happened, when, on which property)
- Goal of the sequence (re-engage / get a decision / book a tour / get the LOI signed)

---

## Sequence Format

**Touch 1 -- Text (same day or next day)**
Short, personal, no ask. Reference the specific property + something concrete from the last interaction. 2-3 sentences max.

**Touch 2 -- Email (3-5 days later)**
More substance. Share something useful (Matterport link, comp data, a question they had answered, market intel). Soft CTA.

**Touch 3 -- Text (5-7 days after Touch 2)**
Brief check-in. Direct but not pushy. Give them an easy out if timing isn't right.

---

## Tone

- Sound like an operator, not a drip campaign
- Use their name once per message
- Reference specific details -- the suite they toured, the SF they need, the rate they pushed back on
- Never say "just checking in" -- always give them a reason to respond
- Match the relationship: brokers get peer-to-peer voice, prospect tenants get warmth + clarity
